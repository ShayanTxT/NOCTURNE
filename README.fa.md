# ♪ TermVibe

**موزیک پلیر خفن ترمینال — ویژوالایزر زنده، سیک روی موج صدا، تِم‌های نئونی. ۱۰۰٪ آفلاین.**

[مستندات انگلیسی](README.md)

![اسکرین‌شات TermVibe](docs/screenshot.svg)

</div>

یک آدرس فولدر بهش می‌دی، همه‌ی آهنگ‌های داخلش (حتی زیرپوشه‌ها) رو پیدا می‌کنه،
پلی‌لیست می‌سازه و پخش می‌کنه — با آنالایزر طیفی واقعی (FFT)، نوار سیک روی شکل
موج صدا، شافل و ریپیت، فیلتر زنده‌ی پلی‌لیست و پنج تِم نئونی. **نه اکانت می‌خواد،
نه اینترنت، نه هیچی — موسیقی‌ات هیچ‌وقت از سیستم‌ت خارج نمی‌شه.**

## ✨ امکانات

- 🎵 **پخش همه‌ی فرمت‌های libsndfile** — `FLAC`، `WAV`، `OGG/Opus`، `AIFF` و…
- 📊 **ویژوالایزر طیفی زنده** — FFT واقعی با باند‌های لگاریتمی، اسموثینگ، کپ‌های در حال سقوط و گین خودکار
- 〰️ **نوار سیک موجی** — از خودِ شکل موج آهنگ ساخته می‌شه؛ کلیک یا درگ کن تا هر جا خواستی بری
- 📂 **فولدر = پلی‌لیست** — اسکن بازگشتی با مرتب‌سازی طبیعی (`track2` قبل از `track10`)، خوندن تگ‌های ID3/Vorbis (نام، خواننده، آلبوم، بیت‌ریت، سال)
- 🔀 **شافل و ریپیت** (خاموش / همه / یکی) با پخش خودکار آهنگ بعدی
- 🎨 **۵ تِم نئونی** — `synthwave`، `matrix`، `sunset`، `ice`، `candy` — با `t` عوض کن
- 🧘 **حالت زِن** — فقط ویژوالایزر غول‌پیکر، بقیه‌چیز مخفی
- 🔍 **فیلتر فوری** — `/` رو بزن و تایپ کن؛ بر اساس نام، خواننده یا اسم فایل
- 💾 **خروجی M3U** (`ctrl+s`)، یادآوری آخرین فولدر، ولوم و تِم
- 🔇 **حالت بی‌صدا** (`--silent`) — کل رابط کاربری بدون کارت صدا (دمو، CI، سرور)

## 🚀 شروع سریع

```bash
git clone https://github.com/YOUR_USERNAME/termvibe.git
cd termvibe
pip install .

# برای تست فوری، چند آهنگ دمو می‌سازه (بدون دانلود):
python scripts/make_demo_tracks.py
termvibe demo_tracks
```

یا مستقیم کتابخانه‌ت رو بده:

```bash
termvibe ~/Music                 # اسکن بازگشتی و پخش
termvibe ~/Music --flat          # فقط خود پوشه، بدون زیرپوشه
termvibe ~/Music -s -r one       # شافل + ریپیت یکی
termvibe song.flac               # یک فایل تکی
termvibe --theme matrix          # انتخاب تِم
termvibe --list-themes
```

بدون هیچ آرگومانی، آخرین فولدر رو دوباره باز می‌کنه.

### نکته‌ی لینوکس

`sounddevice` به PortAudio نیاز داره:

```bash
sudo apt install libportaudio2        # Debian/Ubuntu
sudo dnf install portaudio            # Fedora
sudo pacman -S portaudio              # Arch
```

روی **ویندوز** و **مک** همه‌چیز داخل پکیج هست — فقط `pip install .`
(برای ویندوز، [Windows Terminal](https://aka.ms/terminal) بهترین نمایش رو می‌ده).

## ⌨️ کلیدها

| کلید | کار |
|---|---|
| `space` | پخش / توقف |
| `n` / `p` | آهنگ بعدی / قبلی |
| `←` `→` | جابه‌جایی −۵ / +۵ ثانیه |
| `,` `.` | جابه‌جایی −۳۰ / +۳۰ ثانیه |
| `+` / `−` | کم/زیاد کردن صدا |
| `m` | بی‌صدا |
| `s` | شافل |
| `r` | حالت ریپیت: خاموش → همه → یکی |
| `t` | تِم بعدی |
| `f` | حالت زِن (ویژوالایزر بزرگ) |
| `/` | فیلتر پلی‌لیست (`esc` پاک می‌کنه) |
| `enter` / کلیک | پخش آهنگ انتخاب‌شده |
| کلیک/درگ روی موج | سیک |
| `o` | باز کردن فولدر یا فایل |
| `F5` | اسکن دوباره‌ی فولدر |
| `ctrl+s` | ذخیره‌ی پلی‌لیست `.m3u` |
| `?` | راهنما |
| `q` | خروج |

## 🎨 تِم‌ها

`synthwave` · `matrix` · `sunset` · `ice` · `candy` — با `t` بچرخون یا با
`--theme matrix` شروع کن. انتخابت ذخیره می‌شه.

## ⚙️ تنظیمات

یک فایل JSON کوچیک (فولدر، ولوم، تِم، شافل، ریپیت):

- لینوکس/مک: `~/.config/termvibe/config.json`
- ویندوز: `%APPDATA%\termvibe\config.json`
