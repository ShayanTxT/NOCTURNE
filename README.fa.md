## ✨ امکانات

- 👾 **سکانس بوت هکری** — لاگ سیستمی که با افکت تایپ زنده میاد بالا و `ACCESS GRANTED` می‌گیره (هر کلیدی ردش می‌کنه، با `--no-boot` خاموش می‌شه)
- 📊 **۳ ویژوالایزر زنده** (با `v` عوض می‌شه):
  - **spectrum** — FFT واقعی با باندهای لگاریتمی، کپ‌های در حال سقوط و گین خودکار
  - **matrix rain** — بارون دیجیتال که با موسیقی می‌رقصه
  - **oscilloscope** — ردیابی خام موج صدا
- 〰️ **نوار سیک موجی** — از شکل موج واقعی آهنگ؛ کلیک یا درگ کن
- 📂 **فولدر = پلی‌لیست** — اسکن بازگشتی، مرتب‌سازی طبیعی، تگ‌های ID3/Vorbis
- 🎵 **پخش همه‌ی فرمت‌های libsndfile** — `FLAC`، `WAV`، `OGG/Opus`، `AIFF` و…
- 🔀 **شافل و ریپیت** (خاموش / همه / یکی) با پخش خودکار و رد کردن فایل‌های خراب
- 🎨 **۵ تم CRT** — `fsociety` (سبز فسفری)، `redroom` (قرمز)، `crt` (کهربایی)، `cipher` (فیروزه‌ای)، `ghost` (بنفش)
- 🧘 **حالت زِن** (`f`) — فقط ویژوالایزر غول‌پیکر
- 🔍 **فیلتر فوری** (`/`) — بر اساس نام / خواننده / اسم فایل
- 💾 **خروجی M3U** و ذخیره‌ی تنظیمات
- 👻 **حالت شبح** (`--silent`) — کل رابط بدون کارت صدا (سرور، CI، دمو)

## 🚀 شروع سریع

```bash
git clone https://github.com/YOUR_USERNAME/nocturne.git
cd nocturne
pip install .

# بدون هیچ دانلودی — چند آهنگ دمو می‌سازه و پخش می‌کنه:
python scripts/make_demo_tracks.py
nocturne demo_tracks
```

```bash
nocturne ~/Music                 # اسکن بازگشتی و پخش
nocturne ~/Music --flat          # بدون زیرپوشه
nocturne ~/Music -s -r one       # شافل + ریپیت یکی
nocturne song.flac               # یک فایل
nocturne --theme redroom         # انتخاب تم
nocturne --no-boot --list-themes
```

بدون آرگومان، آخرین فولدر رو دوباره باز می‌کنه.

### نکته‌ی لینوکس

```bash
sudo apt install libportaudio2        # Debian/Ubuntu
sudo dnf install portaudio            # Fedora
sudo pacman -S portaudio              # Arch
```

روی **ویندوز** و **مک** همه‌چیز داخل پکیجه — فقط `pip install .`
(برای ویندوز [Windows Terminal](https://aka.ms/terminal) بهترین نمونه).

## ⌨️ کلیدها

| کلید | کار |
|---|---|
| `space` | پخش / توقف |
| `n` / `p` | بعدی / قبلی |
| `←` `→` | ±۵ ثانیه |
| `,` `.` | ±۳۰ ثانیه |
| `+` / `−` | صدا |
| `m` | بی‌صدا |
| `v` | ویژوالایزر: طیف → بارون ماتریکسی → اسیلوسکوپ |
| `s` | شافل |
| `r` | ریپیت: خاموش → همه → یکی |
| `t` | تم بعدی |
| `f` | حالت زِن |
| `/` | فیلتر پلی‌لیست |
| `enter` / کلیک | پخش آهنگ |
| کلیک روی موج | سیک |
| `o` | باز کردن فولدر/فایل |
| `F5` | اسکن دوباره |
| `ctrl+s` | ذخیره‌ی M3U |
| `?` | راهنما |
| هر کلید | رد کردن بوت |
| `q` | خروج |

## 🎨 تم‌ها

`fsociety` · `redroom` · `crt` · `cipher` · `ghost` — با `t` بچرخون، با
`--theme redroom` شروع کن. انتخابت ذخیره می‌شه.

## ⚙️ تنظیمات

- لینوکس/مک: `~/.config/nocturne/config.json`
- ویندوز: `%APPDATA%\nocturne\config.json`
